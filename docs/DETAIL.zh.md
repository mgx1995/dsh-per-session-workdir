# 会话独立工作目录

每个会话打开时，插件会在当前工作区根目录创建一个以会话创建时间命名的子文件夹（形如 `2026-11-25_18-50-21`），并把该会话的工作目录切换到这个文件夹。

## 行为

- 文件夹名取自会话的稳定创建时间 `header.createdAt`，格式为 `YYYY-MM-DD_HH-MM-SS`（本地时区），休眠后再次打开同一会话仍回到同一个文件夹。
- 左侧文件树跟随会话的工作目录，切换会话即可看到各自独立的文件。
- 文件夹在会话关闭后保留，不会自动删除。
- 若目录创建或切换失败，会话继续使用原来的工作目录。

## 安装

```sh
dsh plugin --profile <profile> add github:mgx1995/dsh-per-session-workdir
```
